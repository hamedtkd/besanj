# Besanj 1.5.0 - ثبت سریع

## هدف

در نسخه های قبلی بسنج اطلاعات خرید را خوب نگه می داشت، اما ثبت دستی چندین فیلد می توانست از خود یادداشت کردن روی کاغذ کندتر باشد. نسخه 1.5 مسیر ورود اطلاعات را از «فرم کامل» به «ثبت با حداقل ورودی و تکمیل بعدی» تغییر می دهد.

اصل این Release:

> اطلاعات را هنگام نیاز بگیر، نه هنگام ایجاد پرونده.

## ثبت سریع از داشبورد

دکمه «ثبت سریع» در داشبورد دو مسیر دارد:

1. خرید جدید: فقط عنوان کافی است. نوع پیش فرض کالا است و کاربر می تواند با یک لمس آن را خدمت کند. دسته پیش فرض «سایر» است و بودجه، برچسب و شرط ها بعداً قابل تکمیل هستند.
2. قیمت جدید: کاربر می تواند یک پرونده فعال را انتخاب کند یا اجازه دهد همان متن یک پرونده جدید بسازد و استعلام همزمان روی آن ثبت شود.

## متن طبیعی و Paste

ورودی سریع برای متن هایی شبیه نمونه زیر طراحی شده است:

```text
سامسونگ ۵۵ Q70
۶۸ میلیون
موجود
گارانتی ۱۸ ماه
ارسال فردا
۰۹۱۲۱۲۳۴۵۶۷
```

Parser محلی می تواند این بخش ها را پیشنهاد دهد:

- عنوان کالا یا خدمت
- قیمت
- شماره فروشنده
- گارانتی
- موجود / ناموجود / سفارشی
- تحویل فوری، امروز، فردا یا تعداد روز
- اعتبار قیمت
- شرایط پرداخت
- کانال تماس و مرجع تماس

موجودی در این نسخه مدل دیتابیس مستقل ندارد و همراه متن مبنا در یادداشت استعلام نگه داشته می شود. این تصمیم از migration غیرضروری فقط برای Quick Capture جلوگیری می کند.

## مبلغ سریع

`parseQuickToman` ورودی های کوتاه را می پذیرد:

```text
۶۸ میلیون
68م
68,000,000
68000000
```

عدد کوچک بدون واحد، مثل `68`، در مسیر Quick Capture به صورت ۶۸ میلیون تومان پیشنهاد می شود، اما همراه هشدار واضح است و قبل از ثبت باید توسط کاربر تأیید شود.

## عددهای گفتاری فارسی

ماژول `spoken-persian-number.ts` عددهای متداول فارسی را بدون سرویس بیرونی تبدیل می کند. نمونه ها:

```text
شصت و هشت -> ۶۸
دو و نیم میلیون -> ۲٬۵۰۰٬۰۰۰
هجده -> ۱۸
```

ترتیب رقم های تلفن وقتی کاربر رقم ها را جداگانه می گوید نیز قابل تبدیل است.

## Voice to Text محلی

Voice Capture فقط وقتی فعال می شود که مرورگر API تشخیص گفتار روی دستگاه را ارائه کند.

سیاست حریم خصوصی این Release:

- `SpeechRecognition.processLocally = true`
- بررسی زبان فارسی با `SpeechRecognition.available()`
- امکان نصب بسته محلی فارسی با `SpeechRecognition.install()` در مرورگرهای سازگار
- هیچ `processLocally = false` و هیچ fallback ابری در کد وجود ندارد
- اگر دستگاه پشتیبانی نکند، Paste و تایپ بدون محدودیت باقی می مانند

این API هنوز در همه مرورگرها موجود نیست. نبود پشتیبانی Voice نباید هیچ مسیر اصلی دیگری را خراب کند.

## Draft

ثبت نیمه کاره در `localStorage` با کلید زیر نگه داشته می شود:

```text
besanj.quick-capture.v1
```

Draft حداکثر هفت روز معتبر است و بعد از ثبت موفق پاک می شود. Draft شامل متن و فیلدهای موقت Quick Capture است و وارد Backup اصلی نمی شود.

## استفاده دوباره از فروشنده

فهرست Seller Profileهای موجود در ثبت سریع در دسترس است. انتخاب فروشنده قبلی نام، شماره و `sellerProfileId` را دوباره استفاده می کند و `addQuote` همان مسیر سراسری v1.3 را نگه می دارد.

## قیمت جدید همان فروشنده

مسیر استعلام مجدد قبلی در این Release به زبان ساده تر «قیمت جدید» نمایش داده می شود. فروشنده و شرایط قبلی به عنوان preset حفظ می شوند، قیمت قبلی پاک نمی شود و کاربر برای به روزرسانی معمولاً فقط مبلغ تازه را وارد می کند. نتیجه همچنان به همان تاریخچه فروشنده متصل می ماند.

## Progressive Disclosure

فرم عادی «ثبت استعلام» همچنان وجود دارد، اما فیلدهای کم استفاده زیر پیش فرض بسته هستند:

- تاریخ و اعتبار
- زمان تحویل
- روش استعلام
- مرجع تماس
- گارانتی و پرداخت
- پوشش شرط ها
- پیوست
- یادداشت

کاربر با «جزئیات بیشتر، اختیاری» به همه آن ها دسترسی دارد. داده ای که parser از متن پیدا کرده حتی در حالت بسته هم در state فرم قرار می گیرد و هنگام ثبت حفظ می شود.

## کنترل کیفیت

Guard جدید:

```bash
npm run check:quick-capture
```

Guard بررسی می کند:

- ثبت سریع در Dashboard سیم کشی شده باشد
- ساخت Case و Quote فقط از helperهای DB موجود استفاده کند
- Draft محلی وجود داشته باشد
- Voice فقط local باشد و fallback ابری اضافه نشده باشد
- parser عنوان و موجودی را پشتیبانی کند
- مبلغ کوتاه و عدد گفتاری وجود داشته باشند
- Progressive Disclosure فرم اصلی حفظ شده باشد
- تست های Quick Capture وجود داشته باشند
