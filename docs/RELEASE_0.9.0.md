# بسنج 0.9.0 — ثبت سریع و استفاده دوباره از سابقه

این فاز روی کم‌کردن زمان ورود استعلام تمرکز دارد. هدف این است که کاربر بتواند متن یک پیام یا پیش‌فاکتور را داخل فرم بچسباند، فیلدهای قابل تشخیص را به‌صورت پیشنهاد بگیرد و قبل از ثبت همه چیز را بازبینی کند.

## قابلیت‌ها

- «ثبت سریع از متن» داخل فرم استعلام.
- تشخیص محلی و deterministic برای نام فروشنده، موبایل، قیمت، هزینه جانبی، زمان تحویل، گارانتی، شرایط پرداخت، اعتبار نسبی قیمت، روش استعلام و مرجع تماس.
- پشتیبانی از ارقام فارسی/عربی/لاتین و مبلغ تومان/ریال؛ ریال در فرم به تومان تبدیل می‌شود.
- پشتیبانی از عبارت‌هایی مثل «تحویل فوری»، «اعتبار تا فردا»، «اعتبار ۲ روز» و «۱۰ میلیون تومان».
- هیچ داده‌ای خودکار ذخیره نمی‌شود؛ parser فقط فرم را پر می‌کند و ثبت نهایی همچنان با کاربر است.
- متن مبنا در صورت خالی بودن یادداشت، داخل یادداشت نگه داشته می‌شود تا منبع استعلام از دست نرود.
- فروشنده‌های پرونده‌های قبلی در انتخاب سریع فرم ظاهر می‌شوند و بدون ساخت schema جدید می‌توان نام و شماره را دوباره استفاده کرد.
- فروشنده‌های تکراری بین پرونده‌ها با نام/شماره نرمال‌شده deduplicate می‌شوند.
- Guard جدید `check:capture`.
- Service Worker cache version: `besanj-shell-v10`.

## محدودیت عمدی

Parser هوش مصنوعی نیست و برای متن‌های مبهم حدس قطعی نمی‌زند. وقتی چند مبلغ وجود داشته باشد یا قیمت قابل اتکایی پیدا نشود، هشدار می‌دهد تا کاربر فرم را بررسی کند.
