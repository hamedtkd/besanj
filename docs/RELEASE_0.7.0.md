# Release 0.7.0 — Reporting, timeline & quick contact

## Product goal

فاز 0.6 مالکیت و انتقال داده را حل کرد. فاز 0.7 روی دو سؤال بعدی تمرکز دارد:

1. بعد از مقایسه چطور سریع با فروشنده وارد اقدام شوم؟
2. چطور نتیجه یک پرونده را تمیز، قابل چاپ و قابل اشتراک ارائه کنم؟

## Quick contact

روی کارت آخرین استعلام هر فروشنده اکشن‌های سریع اضافه شده‌اند:

- تماس تلفنی
- پیامک
- واتساپ برای شماره موبایل معتبر ایران
- کپی متن آماده پیگیری

متن پیگیری از داده همان پرونده ساخته می‌شود و در صورت وجود، قیمت و تاریخ اعتبار را هم وارد می‌کند. لینک واتساپ شماره‌های 09 را به فرمت بین‌المللی 98 تبدیل می‌کند.

## Case timeline

تب «رویدادها» از داده فعلی یک timeline خوانا می‌سازد. در این نسخه جدول event-log جدیدی اضافه نشده و رویدادها از داده‌های موجود استنتاج می‌شوند:

- ساخت پرونده
- اضافه‌شدن فروشنده
- ثبت استعلام
- ساخت و تکمیل پیگیری
- اضافه‌شدن فایل
- انتخاب نهایی فعلی

این تصمیم عمداً Schema را روی نسخه 4 نگه می‌دارد و migration تازه‌ای لازم ندارد.

## Report page

مسیر جدید:

```text
/cases/[id]/report
```

گزارش شامل موارد زیر است:

- وضعیت پرونده
- تعداد فروشنده و استعلام
- کمترین قیمت و اختلاف قیمت
- بودجه هدف و شروط خرید
- انتخاب نهایی
- آخرین قیمت هر فروشنده
- تحویل، گارانتی، پوشش شروط و تعداد فایل
- پیگیری‌های باز

اگر انتخاب نهایی به یک quote قدیمی اشاره کند و فروشنده بعداً quote تازه‌تری ثبت کرده باشد، انتخاب تاریخی در بخش «انتخاب نهایی» گزارش حفظ می‌شود.

## Share & PDF

- Web Share API در مرورگرهای پشتیبانی‌شده
- fallback به Clipboard
- Print stylesheet مستقل از Dark Mode
- A4 print layout
- `window.print()` برای چاپ یا Save as PDF مرورگر

هیچ dependency جدیدی برای PDF اضافه نشده است.
