# Besanj 0.4.5

- نام محصول در تمام نقاط کاربرمحور از «استعلام‌کو» به «بسنج» تغییر کرد.
- Metadata، عنوان مرورگر، Apple Web App و Web Manifest با نام «بسنج» هماهنگ شدند.
- متن نصب PWA اکنون «نصب بسنج» است.
- نام پکیج پروژه به `besanj` تغییر کرد.
- شناسه‌های داخلی قبلی مانند `estelamkoo-local` و کلیدهای storage عمداً حفظ شدند تا داده و تنظیمات کاربران نسخه‌های قبلی از بین نروند.
- لوگو، favicon، آیکن‌های PWA و Maskable همان هویت بصری جدید Besanj باقی ماندند.
