# Release 0.3.0 — UX cleanup, charts, settings

این release روی بازخورد واقعی نسخه 0.2 تمرکز دارد و schema دیتابیس را تغییر نمی‌دهد.

## اصلاح‌ها

- Selectها `items` map دارند تا label فارسی نمایش داده شود؛ raw valueهایی مثل `balanced` و UUID دیگر در trigger دیده نمی‌شوند.
- PriceInputها فقط TomanIcon دارند و متن تکراری «تومان» حذف شده است.
- تب مقایسه از table شلوغ به card grid responsive تبدیل شده است؛ اکشن‌ها به دو اکشن ثانویه در footer هر کارت محدود شده‌اند و انتخاب نهایی کنار قیمت قرار گرفته است.
- آیکون تصمیم‌یار در tab bar کوچک و هم‌اندازه سایر آیکون‌ها شده است.
- تصمیم‌یار مرحله انتخاب فروشنده دارد و کاربر می‌تواند همان‌جا ۲ تا ۴ گزینه را اضافه/حذف کند.

## نمودار

- حالت پیش‌فرض: horizontal bar chart آخرین قیمت هر فروشنده، مرتب‌شده از ارزان به گران.
- حالت دوم: scatter/time chart همه استعلام‌های تاریخی.
- برای فروشنده‌ای که بیش از یک قیمت دارد، نقاط تاریخی با خط همان سری به هم متصل می‌شوند.
- هر فروشنده در حالت زمانی قابل hide/show است.

## تنظیمات ظاهر

- System / Light / Dark
- paletteهای amber / blue / violet / rose
- persistence در localStorage
- theme-color مرورگر با palette انتخاب‌شده sync می‌شود.

## سازگاری داده

Dexie schema همچنان v2 است. هیچ migration جدیدی اجرا نمی‌شود و داده v0.2 دست‌نخورده باقی می‌ماند.
