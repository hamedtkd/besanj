# Besanj 1.2.0: Categories, Tags & Monthly Budgets

## هدف

این Release به بسنج امکان می دهد علاوه بر تصمیم هر خرید، تصویر کلی نوع هزینه و مصرف بودجه ماهانه را هم نشان دهد. همه محاسبات local-first و deterministic هستند و Backend یا AI اضافه نشده است.

## قابلیت های جدید

### دسته بندی پرونده

- دسته های آماده: لوازم خانگی، دیجیتال، درمان، خودرو، خدمات، خانه، سفر و سایر.
- دسته سفارشی.
- نمایش دسته روی کارت، صفحه پرونده و گزارش.
- امکان تغییر دسته از بخش برنامه خرید.

### برچسب

- چند برچسب آزاد برای هر پرونده.
- نرمال سازی فارسی و حذف برچسب تکراری.
- حداکثر ۸ برچسب برای هر پرونده.
- نمایش برچسب در کارت و پرونده.
- فیلتر Dashboard و Insights بر اساس برچسب.

### بودجه ماهانه

- سقف کل ماه.
- سقف جدا برای دسته ها.
- محاسبه مصرف بر اساس مبلغ واقعی خرید ثبت شده.
- محاسبه ماه بر اساس تقویم فارسی و منطقه زمانی تهران.
- مقدار مصرف شده و باقی مانده.
- هشدار نزدیک سقف از ۸۰ درصد.
- وضعیت عبور از سقف.
- خلاصه بودجه در داشبورد.
- تنظیم و جزئیات بودجه در `/insights#budget`.

### Insights

- فیلتر دسته.
- فیلتر برچسب.
- نمودار هزینه واقعی بر اساس دسته.
- Seller Memory و شاخص های خرید روی مجموعه فیلترشده محاسبه می شوند.

### Backup / Restore

- دسته و برچسب داخل رکورد پرونده پشتیبان گیری می شوند.
- store بودجه در Backup اضافه شده است.
- فایل های Backup قدیمی که `budgetPlans` ندارند همچنان معتبر هستند.
- validation سقف های بودجه از مقدارهای صفر، منفی یا ناسازگار جلوگیری می کند.

## معماری و داده

Dexie schema از **v4 به v5** ارتقا یافته است.

store جدید:

```text
budgetPlans: &id, updatedAt
```

شناسه تنظیم فعلی:

```text
monthly
```

فیلدهای اختیاری جدید روی `PurchaseCase`:

```text
categoryKey
categoryLabel
tags
```

مدل جدید:

```text
BudgetPlan
```

Migration v5 داده های قدیمی را حذف نمی کند. دسته و برچسب اختیاری هستند و پرونده های نسخه های قبلی بدون نیاز به مقدار پیش فرض اجباری قابل استفاده می مانند.

## فرمت Backup

`formatVersion` همچنان **1** است. تغییرات جدید additive و optional هستند و parser جدید فایل نسخه های قبلی را می پذیرد، بنابراین شکستن عمدی سازگاری Backup لازم نبود.

- ویرایش برنامه خرید.
- فیلتر Dashboard.
- خلاصه و تنظیم بودجه.
- فیلتر و نمودار دسته در Insights.
- Backup/Restore دسته، برچسب و بودجه.
