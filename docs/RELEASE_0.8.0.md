# بسنج 0.8.0 — اعلان و اقدام روزانه

این نسخه فاز «اتوماسیون محلی» را اضافه می‌کند و روی پیگیری‌های v0.5 و PWA فعلی سوار می‌شود.

## قابلیت‌های جدید

- درخواست مجوز Web Notification از داخل تنظیمات، فقط با اقدام مستقیم کاربر.
- انتخاب نوع اعلان: پیگیری سررسیدشده، اعتبار قیمت، قیمت قدیمی و آماده تصمیم.
- پیش‌فرض کم‌مزاحمت: فقط پیگیری‌ها و قیمت‌های رو به انقضا فعال‌اند.
- جلوگیری از اعلان تکراری: هر Task در هر روز حداکثر یک‌بار اعلان می‌شود.
- اگر چند Task تازه هم‌زمان وجود داشته باشد، یک اعلان خلاصه فرستاده می‌شود.
- کلیک روی اعلان، پرونده مربوط یا داشبورد را باز می‌کند؛ Service Worker پنجره موجود را focus/navigate می‌کند.
- App Badge برای تعداد کارهای امروز در مرورگرهای پشتیبان.
- شمار کارهای امروز روی آیکن Bell در Navbar دیده می‌شود.
- Snooze مستقیم پیگیری از «کارهای امروز»: فردا، ۳ روز دیگر یا یک هفته دیگر.
- دکمه «انجام شد» همچنان مستقیماً Reminder را می‌بندد.
- Cache نسخه PWA به `besanj-shell-v9` افزایش یافت.
- Guard جدید `check:automation` به pipeline کامل اضافه شد.

## محدودیت آگاهانه

بسنج هنوز local-first و بدون Backend/Push Server است. Web Notification بدون Push Server نمی‌تواند در همه مرورگرها و سیستم‌عامل‌ها زمانی که اپ کاملاً بسته است اجرای background دقیق و تضمین‌شده داشته باشد. در v0.8 بررسی اعلان در این نقاط انجام می‌شود:

1. اجرای اپ و hydrate شدن تنظیمات.
2. تغییر داده‌های پرونده/استعلام/Reminder در IndexedDB.
3. برگشتن tab/PWA به حالت visible یا focus.
4. هر ۱۵ دقیقه تا وقتی اپ باز و visible است.

این رفتار عمداً در UI توضیح داده شده تا محصول ادعای Push پس‌زمینه‌ای نداشته باشد.

## گیت

```bash
npm run check
```

به‌علاوه برای منطق اعلان و Snooze تست مستقل اضافه شده است. برای کنترل regression timezone می‌توان تست‌ها را با `TZ=Asia/Tehran` نیز اجرا کرد.
