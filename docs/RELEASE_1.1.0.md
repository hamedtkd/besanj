# Besanj 1.1.0 — Purchase Insights & Seller Memory

## هدف

بعد از کامل‌شدن چرخه خرید در 1.0، این نسخه داده نتیجه خرید را به بینش قابل استفاده برای خریدهای بعدی تبدیل می‌کند؛ بدون Backend و بدون تغییر Schema دیتابیس.

## قابلیت‌ها

- مسیر جدید `/insights`.
- مجموع هزینه واقعی و صرفه‌جویی در خریدها.
- نرخ تحویل به‌موقع، میانگین تعداد استعلام و زمان تصمیم.
- وضعیت خریدهای داخل/خارج بودجه.
- نمودار هزینه ماهانه تا ۱۲ ماه اخیر.
- حافظه بین‌پرونده‌ای فروشنده با dedupe بر اساس شماره و سپس نام نرمال‌شده.
- آمار فروشنده شامل تعداد پرونده، استعلام، برد خرید، مبلغ خرید، میانگین امتیاز و تحویل به‌موقع.
- برجسته‌سازی بیشترین صرفه‌جویی، بیشترین عبور از بودجه و فروشنده پرتکرار.
- لینک بینش‌ها در Navbar و Dashboard.
- `.gitattributes` با LF پایدار برای کاهش warningهای line ending روی Windows.
- `check:insights` guard.
- Service Worker `besanj-shell-v12`.

## داده

Schema دیتابیس همچنان نسخه 4 است. هیچ جدول یا index جدیدی اضافه نشده و تمام Insightها در زمان نمایش از `purchaseCases`, `providers` و `quotes` محاسبه می‌شوند.
