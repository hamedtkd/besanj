# Besanj 1.0.0 — Purchase Completion

نسخه 1.0 حلقه خرید را از استعلام تا نتیجه واقعی کامل می‌کند.

## قابلیت‌های جدید

- ثبت نتیجه خرید روی استعلام انتخاب‌شده.
- مبلغ واقعی پرداخت‌شده، تاریخ خرید، شماره سفارش/رسید، تاریخ تحویل مورد انتظار، تاریخ دریافت و یادداشت.
- دو وضعیت سفارش: «سفارش ثبت شده» و «دریافت شده».
- کارت نتیجه خرید با اختلاف مبلغ واقعی نسبت به استعلام و بودجه و صرفه‌جویی نسبت به گران‌ترین گزینه.
- قفل انتخاب نهایی بعد از ثبت خرید برای جلوگیری از جدا شدن نتیجه واقعی از استعلام مبنا.
- جلوگیری از حذف استعلامی که نتیجه خرید به آن متصل است.
- نمایش نتیجه خرید در گزارش چاپی/متنی و Timeline.
- Delivery task برای خریدهای سفارش‌شده با موعد تحویل امروز، فردا یا عقب‌افتاده.
- اعلان محلی Delivery به‌صورت پیش‌فرض فعال است.
- Backup parser نتیجه خرید و ارتباط آن با quote انتخاب‌شده را اعتبارسنجی می‌کند.
- نسخه app داخل Backup به 1.0.0 اصلاح شد.
- Service Worker cache به `besanj-shell-v11` ارتقا یافت.
- Guard جدید `check:purchase`.

## مدل داده

جدول جدیدی اضافه نشده است. `PurchaseCase` یک فیلد اختیاری `purchaseOutcome` دارد؛ بنابراین Dexie schema همچنان v4 است و migration تازه‌ای لازم نیست.
