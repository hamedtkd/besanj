# Besanj 0.4.2

## تقویم و تم

- پوستهٔ تقویم Doran به‌طور کامل به tokenهای Besanj/Poolamkoo متصل شد؛ سطح، متن، border، primary، focus ring و حالت تاریک همگی از تم فعال برنامه می‌آیند.
- active month/year با `aria-selected` و class رسمی Doran به‌صورت صریح استایل می‌شود تا در پالت‌های مختلف و Dark Mode محو نشود.
- هدر ماه/سال، فلش‌های ناوبری، پنل ماه‌ها و پنل سال‌ها stroke و contrast واضح‌تری دارند.
- wrapper کل تقویم اکنون `estelamkoo-doran` است؛ در نتیجه هدر و پنل‌ها یک context تم مشترک دارند.

## دسترسی سریع تم

- یک toggle مستقیم Light/Dark به Navbar اضافه شد.
- یک popover سریع تم به Navbar اضافه شد که System / Light / Dark و چهار پالت آماده را بدون بازکردن Settings تغییر می‌دهد.
- رنگ سفارشی از همان quick menu قابل بازکردن است و Settings کامل همچنان باقی مانده است.

## داشبورد

- Hero و summary dashboard بازطراحی شدند و تعداد پرونده فعال، کل استعلام‌ها، پرونده‌های نیازمند پیگیری و تصمیم‌های نهایی را نشان می‌دهند.
- جست‌وجوی عنوان/توضیح پرونده اضافه شد.
- فیلتر نوع پرونده: همه / کالا / خدمت.
- فیلتر وضعیت استعلام: همه / نیاز به پیگیری / دارای استعلام / بدون استعلام.
- مرتب‌سازی: آخرین تغییر / جدیدترین استعلام / بیشترین استعلام / کمترین قیمت.
- شمارندهٔ نتایج و reset همه فیلترها اضافه شد.
- کارت پرونده‌ها hierarchy قوی‌تر، indicator قیمت قدیمی، indicator تصمیم نهایی و CTA بصری واضح‌تر دارند.

## تست

- تست واحد برای فیلتر و مرتب‌سازی dashboard اضافه شد.
